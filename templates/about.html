About

{{ title }} is a small, self-hosted paste and blob host written in Common Lisp. It has no database: every blob is a directory on disk holding the raw bytes and a small metadata file. Nothing here needs JavaScript, so curl, eww, w3m and lynx get the same thing a graphical browser gets. The one exception is the copy shortcut next to a freshly stored link, which is added by a script when there is one to run and simply absent otherwise.

What it accepts

{{ types }}, up to {{ max-size }} per upload. The type is decided by reading the first bytes of the file, never from its extension or from the header the client sent: renaming a file changes nothing, and anything that is not on the list is refused. That keeps executables and SVG out. Archives are accepted but never opened, listed or decompressed: they are stored and handed back as opaque bytes, always as a download.

The stored name is sanitized and given the extension its real type deserves. An upload with no usable name is named after its own id.

Reading

{{ base-url }}b/<id> answers with the stored bytes and nothing else: no viewer, no markup, no rewriting. Text is served as text/plain, so a paste full of HTML is shown, never rendered. Images and PDFs open in the browser; add ?dl=1 to any blob URL to download it instead. Archives always download.

Ids are random and are not listed anywhere public, so a link is only as private as the people you hand it to.

Writing, from the shell

curl -u admin:PASSWORD --data-binary @notes.txt {{ base-url }}new
cat notes.txt | curl -u admin:PASSWORD --data-binary @- {{ base-url }}new
curl -u admin:PASSWORD -F f=@shot.png {{ base-url }}new

The answer is the URL, as plain text. Add ?name=notes.txt to keep a filename. A refused upload answers with a 400 and a one-line reason.

Listing, from the shell

curl -u admin:PASSWORD '{{ base-url }}admin?raw=1'
curl -u admin:PASSWORD -d id=aaAsJk2 -d id=bbCdEf3 -d confirm=1 {{ base-url }}admin/delete

The listing is tab separated: id, name, type, size, creation time. Without confirm=1 a delete answers with what it would remove instead of removing it.
